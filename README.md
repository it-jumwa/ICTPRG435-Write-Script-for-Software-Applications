## Learning Outcomes
- This unit describes the skills and knowledge required to plan, design, and build scripts, using a scripting language to construct highly interactive and automated software applications
- It applies to those who build and integrate interactive applications or websites for internal or public sites
- They may work as application developers, application-support personnel, programmers specialising in a scripting language, web application programmers, or web developers
